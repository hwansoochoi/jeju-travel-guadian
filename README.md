# 스마트 세이프 트래블 가디언 (Safe Travel Guardian) 🛡️

> **제주 및 전국 단독·안심 여행자를 위한 9대 전방위 스마트 세이프티 & 긴급 구난 통합 플랫폼**

자연재해·조난부터 도심 범죄·신변 위협까지, **상시 감시의 거부감은 없애고 단독 여행자의 위기 골든타임을 지키는 실시간 통합 수호 솔루션**입니다.

---

## 🌟 9대 핵심 안전 체계

1. **공공기관 데이터 실시간 연동**: 기상청 실시간 날씨·기상특보, 한국천문연구원 일출·일몰 시간(당일 일몰 30분 전 산악 하산 권고), 국립해양조사원 만조 데이터(만조 40분 전 해안 갯바위 대피 경보)
2. **범죄다수 발생지역 지오펜싱**: 경찰청 치안통계 및 지자체 범죄지도 연계, 우범지대 및 가로등 취약 골목 진입 시 햅틱 진동 및 안전 우회로 권고
3. **인근 성범죄자 주거지 안내**: 여성가족부 ‘성범죄자 알림e’ 공공데이터 연계, 반경 200m 접근 시 프라이버시 보호형 지능형 사전주의 가이드 발송
4. **단독여행자 실시간 궤적추적**: 올레길·등산로 브레드크럼(Breadcrumb) 이동 궤적 실시간 기록, 코스 이탈 자동 감지 및 통신 음영 직전 **라스트 핑(Last Ping)** 좌표 백업
5. **2단계 체크인 (데드맨 스위치)**: 위험구역 10분 정체 시 본인 확인(진동/화면탭/음성) ➔ 3분간 무응답 시에만 보호자 및 119 전파로 **오경보 90% 차단**
6. **강제 최대 볼륨 비상 사이렌**: 매너모드/진동 상태 강제 해제, 120dB급 소방/경찰 주파수 변조 사운드(**Web Audio API 실시간 합성**) 및 화면 스트로브 플래시 점멸
7. **여행자 안심포인트 & 최단경로 안내**: 학교지킴이집, 24시 안심편의점, 주유소, 관공서(지구대/파출소) 위치 및 비상 시 원터치 최단 안전 도보 내비게이션 연동
8. **인근 병원 및 응급의료 안내**: 야간/휴일 진료 병·의원, 권역 응급의료센터, 공공 심장충격기(AED) 핀포인트 안내 및 원클릭 응급실 직통 연결
9. **피어(동서비스 이용자) SOS**: 반경 1km 내 동일 앱 이용자 및 등록된 로컬 지킴이(주민, 상인)에게 즉각 긴급 푸시 전파

---

## 📂 프로젝트 구성

- `index.html`: 10개의 프레젠테이션 슬라이드 및 9번 슬라이드의 **라이브 인터랙티브 시뮬레이션 콘솔**이 포함된 단일 완성형 웹 애플리케이션
- `worker.js`: Cloudflare Workers 배포용 초경량 서빙 스크립트

---

## 🚀 실행 및 배포 방법

### 1. 로컬에서 실행
`index.html` 파일을 브라우저로 열거나, VS Code의 Live Server 플러그인으로 실행합니다.
- 키보드 [←], [→] 또는 [Space]로 슬라이드 이동
- 슬라이드 9번에서 실제 비상 사이렌 소리(Web Audio API), 지오펜스 알림, 안심포인트 경로 탐색, 보호자 긴급 연락 모달 체험 가능

### 2. Cloudflare Workers 배포
`worker.js` 코드를 Cloudflare Workers 대시보드에 붙여넣고 `Save and Deploy`를 진행합니다.
